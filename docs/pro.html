From license to first source

  1. Request access. Agree the license and distribution channel for your team. See pricing.
  2. Install the supplied package. Receive an authorized wheel or private repository access, plus installation instructions and the Pro notebooks.
  3. Configure the boundary. Set up the Pro license, owner keys, source adapter and agent-to-source permission. Installing the library alone does not activate encryption on existing sources.
  4. Verify your workflow. Confirm that the agent receives only the permitted public view, then validate formulas and decrypt locally.
Distribution policy: Pro is not distributed through public PyPI. The implementation, package downloads and full Pro notebooks require authorized access. The public examples use synthetic data and do not include a Pro runtime or a license.

Core stays open source

The MIT-licensed trustchain Core remains publicly installable from PyPI. Its five notebooks cover signing, receipts, tamper detection and bounded tool workflows. They do not require Pro.
